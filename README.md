# Smart Expense Tracker 

## About the Project
Smart Expense Tracker is a Java desktop application that we are developing as a group project. It helps users manage their daily income and expenses, keep track of their transactions, and manage their monthly budget in one place.

Through this project, we aimed to make personal expense management simple and easy to use while improving our knowledge of Java and database connectivity.

## Features
- User registration and login
- Dashboard to view income, expenses, and balance
- Add and manage income and expenses
- View transaction history
- Set a monthly budget
- Track spending and receive budget alerts
- Store data using MySQL

## Technologies Used
- Java
- Java Swing
- MySQL
- JDBC
- Maven

## How to Run
1. Clone or download this repository.
2. Open the project in a Java IDE.
3. Create the required MySQL database and tables.
4. Update the database connection details in `DBConnection.java`.
5. Build the project using Maven.
6. Run `LoginGUI.java` to start the application.

## What We Learned
While working on this project, we learned how to build a graphical interface using Java Swing, connect a Java application to MySQL using JDBC, and manage user data and financial transactions. We also gained experience working together as a team and solving programming problems.

## Future Improvements
We plan to add expense charts, savings goals, and more features to help users understand and manage their spending habits.
